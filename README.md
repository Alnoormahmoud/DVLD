# 🪪 DVLD – Driving and Vehicle Licensing Department Management System

## 🧭 Overview
The **DVLD Project** is a complete **Driving and Vehicle Licensing Department Management System** built using **C# Windows Forms**.  
It allows managing clients, licenses, applications, tests, and international driving licenses efficiently in a user-friendly desktop application.

---

## 🛠️ Tools & Technologies
- **Language:** C#  
- **Framework:** .NET Framework (Windows Forms)  
- **Database:** SQL Server  
- **File Storage:** JSON / CSV  
- **Libraries:** ADO.NET  
- **IDE:** Microsoft Visual Studio  
- **Version Control:** Git & GitHub

## 🧰 Main Classes and Their Roles

| Class Name                  | Description                                                           |
|-----------------------------|-------------------------------------------------------------------------|
| `clsClient`                 | Manages client account information                                    |
| `clsClientsData`            | Handles list operations for clients (Add, Update, Delete, Search)      |
| `clsLicense`                | Manages driver license information and status                          |
| `clsInternationalLicense`   | Manages international license records                                  |
| `clsTest`                   | Handles driving test results and appointments                          |
| `clsApplication`            | Manages license applications                                          |
| `clsDatabase`               | Handles database connection and SQL operations                         |
| `clsUser`                   | Manages user login and authentication                                 |

---

## ⚙️ Main Features
- 👤 **Client Management** – Add, update, delete, and view driver records.  
- 🪪 **License Management** – Create, renew, and revoke licenses.  
- 🌍 **International License** – Issue and track international driving licenses.  
- 🧪 **Driving Tests** – Schedule, manage, and store driving test results.  
- 📝 **Applications** – Manage new license applications and approvals.  
- 🔐 **User Login** – Simple authentication system for secure access.  
- 🗄️ **Database Integration** – Secure and reliable data storage in SQL Server.  
- 📊 **Reports** – Generate and view application and license reports.
